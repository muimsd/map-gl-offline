# MapLibre GL Example

A demo app showing `map-gl-offline` with MapLibre GL JS.

## Setup

```bash
npm install
```

Create a `.env` file with your MapTiler API key:

```env
VITE_MAPTILER_API_KEY=your_api_key_here
```

Get a free key from [MapTiler](https://www.maptiler.com/).

## Run

```bash
npm run dev
```
